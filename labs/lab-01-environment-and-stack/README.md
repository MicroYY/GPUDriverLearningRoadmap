# Lab 01：环境准备与图形栈总览

## 对应 Session

- [Session 01：环境准备与图形栈总览](../../sessions/session-01-environment-and-stack/README.md)

## 目标

搭建后续学习 GPU 驱动所需的 Linux 环境、源码工作区和基础工具链。

## 任务

1. 准备 Linux 测试环境，优先使用 QEMU 或独立测试机。
2. 下载 Linux 内核、Mesa、libdrm 源码。
3. 安装 `clangd`、`ctags`、`ripgrep`、`gdb`、`perf`。
4. 用一张图概括应用到 GPU 的整体栈结构。

## 交付物

- 环境说明文档
- 图形栈总览图
