# Lab 3：阅读一个 buffer object 的生命周期

## 目标

通过追踪一个 buffer object 的创建、映射、使用和释放过程，理解显存管理在驱动中的基本实现方式。

## 对应模块

- [模块 3：Linux DRM/KMS 核心](../../modules/module-03-drm-kms/README.md)
- [模块 4：真实驱动源码阅读](../../modules/module-04-driver-reading/README.md)

## 建议对应周次

- 第 11 周可先在公共层建立概念
- 第 16 到 18 周可在真实驱动中再做一次

## 任务

1. 选择一个驱动或 DRM 公共层中的 buffer object 路径。
2. 跟踪创建流程。
3. 跟踪映射或绑定流程。
4. 跟踪释放流程。
5. 总结对象在这条路径中经历的状态变化。

## 建议关注点

- object 是在哪创建的？
- object 与 GEM 或 TTM 的关系是什么？
- CPU 映射和 GPU 使用分别走哪条路径？
- 生命周期结束时如何清理？

## 交付物

- 一篇生命周期分析笔记。
- 一张 BO 生命周期流程图。

## 验收标准

- 能清楚解释 BO 从创建到释放的主要步骤。
- 能指出关键结构体和函数入口。
