# Lab 1：环境准备与源码工作区

## 目标

搭建后续学习 GPU 驱动所需的基本环境，并形成一个稳定可复用的源码阅读工作区。

## 对应模块

- [模块 1：基础准备](../../modules/module-01-foundations/README.md)

## 建议对应周次

- 第 1 到 5 周

## 任务

1. 准备 Linux 开发环境。
2. 下载 Linux 内核源码。
3. 下载 Mesa 和 `libdrm` 源码。
4. 安装 `clangd`、`ctags`、`ripgrep`、`gdb`、`perf`。
5. 建立自己的笔记和图示目录。

## 交付物

- 环境说明文档。
- 工具安装记录。
- 你自己的源码导航方式说明。

## 验收标准

- 能够在本地搜索内核和 Mesa 源码。
- 能够定位 DRM 核心目录和至少一个具体驱动目录。
- 能够开始记录学习笔记。
