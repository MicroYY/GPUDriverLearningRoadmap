# Lab 23：选方向深挖

## 对应 Session

- [Session 23：选方向深挖](../../sessions/session-23-specialization/README.md)

## 目标

为下一阶段选择一个明确方向，并制定深入计划。

## 开始前先确认

- 已经完成 Session 23。
- 已经知道自己的硬件条件、兴趣方向和主要短板。

## 任务

### 1. 选一个方向

从下面方向里选一个主线：

- 图形驱动。
- 计算驱动。
- 移动 GPU。
- PC GPU。
- Windows WDDM。

不要同时选多个主线，最多列一个备选方向。

建议给每个方向打分：

```text
兴趣：
硬件条件：
源码可读性：
可验证性：
职业相关度：
4 周内能否产出完整作品：
```

### 2. 列出目标驱动 / 资料 / 文档

至少包含：

- 目标源码目录。
- 关键文档。
- 关键工具。
- 必要硬件或虚拟化环境。
- 第一批要读的 5 个入口。

### 3. 制定未来 4 到 8 周计划

每周都写清：

- 学习主题。
- 要读的源码入口。
- 要做的 lab 或验证。
- 输出物。

### 4. 写明风险和替代方案

```text
最大风险：
缺少的硬件或环境：
如果无法运行实验，源码替代路径：
如果主线太大，收缩到哪条路径：
备选方向：
```

## 交付物

- 专题计划
- 阅读清单
- 方向评分表
- 风险与替代方案

## 检查项

- [ ] 我选定一个主线方向。
- [ ] 我列出目标源码和资料。
- [ ] 我写出至少 4 周计划。
- [ ] 我写明了环境风险和降级方案。

## 完成标准

- 你不只是“想深入”，而是已经知道下一周打开哪个目录、验证什么问题。
