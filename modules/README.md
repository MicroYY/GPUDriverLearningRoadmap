# 课程模块导航

课程按“从基础到驱动源码”的顺序组织，每个模块都建议搭配至少一个 lab。

## 模块列表

1. [模块 1：基础准备](module-01-foundations/README.md)
2. [模块 2：GPU 与图形基础](module-02-gpu-basics/README.md)
3. [模块 3：Linux DRM/KMS 核心](module-03-drm-kms/README.md)
4. [模块 4：真实驱动源码阅读](module-04-driver-reading/README.md)
5. [模块 5：专题攻坚](module-05-advanced-topics/README.md)

## 建议使用方式

- 先读模块 README，明确这一阶段的目标和核心概念。
- 再根据模块建议阅读源码和资料。
- 完成配套 lab，并把结果沉淀到 `notes/` 和 `diagrams/`。

## 与 roadmap 和 labs 的关系

- `modules` 负责按主题组织课程内容。
- `docs/roadmap.md` 负责按周安排学习节奏。
- `labs` 负责把模块中的概念变成可验证的动手任务。

一个模块通常覆盖连续几周，也可能对应多个 lab。
