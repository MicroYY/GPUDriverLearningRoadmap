# 模块 5：专题攻坚

## 目标

围绕显存管理、调度、同步、显示输出和故障恢复做专题深挖。

## 专题方向

- 显存管理：VRAM、GTT、页表、迁移、pin/unpin。
- 调度与同步：scheduler、fence、timeline、hang detect。
- 显示输出：modeset、page flip、vblank、hotplug。
- 地址空间：GPU VM、context switch、隔离。
- 故障恢复：page fault、timeout、GPU reset。
- 调试手段：tracepoint、debugfs、perf、drm debug log。

## 建议产出

- 每个专题一篇问题清单式笔记。
- 至少一次日志分析或调试记录。

## 目标状态

完成这一模块后，你应该已经能独立选择一个具体驱动或具体方向继续深挖。
