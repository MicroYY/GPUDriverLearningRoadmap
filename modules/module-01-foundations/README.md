# 模块 1：基础准备

## 目标

补齐学习 GPU 驱动所需的基础能力，并完成环境准备。

## 核心主题

- C 语言进阶：结构体、位运算、链表、回调。
- 操作系统基础：虚拟内存、页表、中断、DMA。
- 体系结构基础：PCIe、MMU、IOMMU、cache、TLB。
- Linux 驱动基础：模块、设备模型、`ioctl`、`mmap`、锁。

## 建议产出

- 一篇环境搭建文档。
- 一篇 “用户态到内核态调用路径” 笔记。
- 一张内存与 DMA 路径图。
